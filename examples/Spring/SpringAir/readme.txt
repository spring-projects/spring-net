The Visual Studio solution is SpringAir.sln.
In order to be able to run SpringAir you will need to create a 'SpringAir.Web.2010'
virtual directory using IIS Administrator and point it to the following directory :
 examples\Spring\SpringAir\src\SpringAir.Web.2010

Set your startup project as SpringAir.Web.2010
and the start page to .\Web\Home.aspx
